# EduPath - Career Guidance Platform

EduPath is a comprehensive career guidance platform designed to help students make informed decisions about their education and career paths.

## Features

- **Career Assessment Quiz**: Scientific aptitude analysis to find the perfect career match
- **Course Database**: 750+ courses with detailed information and placement statistics
- **College Information**: 3,250+ institutions with rankings, cutoffs, and admission details
- **Scholarship Portal**: Live scholarship opportunities with application tracking
- **Timeline Management**: Personal timeline to track important dates and deadlines
- **Multilingual Support**: Available in multiple languages including Hindi, Urdu, Kashmiri, Spanish, French, German, Chinese, and Arabic

## Live Demo

Visit the live site: [EduPath](https://your-username.github.io/code4cause/edupath-5/)

## Getting Started

1. Open `index.html` in your browser to start exploring
2. Take the career assessment quiz to get personalized recommendations
3. Browse courses, colleges, and scholarships based on your interests
4. Create a personal timeline to track your educational journey

## Project Structure

- `index.html` - Main landing page
- `quiz.html` - Career assessment tool
- `courses.html` - Course exploration page
- `colleges.html` - College information with map integration
- `scholarships.html` - Scholarship opportunities
- `timeline.html` - Personal timeline management
- `career.html` - Career path explorer
- `profile.html` - User profile management
- `auth.html` - Authentication page
- `assets/` - CSS, JavaScript, and other assets
- `api/` - Backend API (for local development)

## Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- Interactive Maps (for college locations)
- Service Worker (for offline functionality)
- Responsive Design (mobile-first approach)
- Progressive Web App features

## Local Development

For full API functionality, you can run the local server:

```bash
cd api
npm install
npm start
```

The site also works as a static website with fallback data when the API is not available.
